# AP Research Game

Browser-based educational game developed for an AP Research study
looking at the effects of game-based learning on student literacy.

## Used
- Node.js
- Express
- Socket.IO (if applicable)
- HTML/CSS/JavaScript

## Deployment
The game is hosted on a cloud-based platform (I used Railway) and accessed through standard web browsers.
No software installation is required on participant devices.
